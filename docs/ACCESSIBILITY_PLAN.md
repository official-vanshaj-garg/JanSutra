# Accessibility Plan (Sahaj Mode)

JanSutra must be accessible to all citizens, including senior citizens, persons with disabilities, and individuals with lower digital literacy. **Sahaj Mode** is our accessibility-first implementation.

## Core Features of Sahaj Mode

1. **Typography & Readability:**
   - Base font size increased to 18px-20px minimum.
   - High-contrast color palette (WCAG AAA compliant where possible).
   - Short, punchy sentences. Jargon is translated to simple concepts.

2. **Keyboard-Friendly UI:**
   - Full logical tab order.
   - Visible focus indicators for all interactive elements.
   - No hover-only interactions.

3. **Semantic HTML:**
   - Strict use of `<h1>` to `<h6>` for document structure.
   - `<main>`, `<nav>`, `<article>`, and `<section>` used properly for screen readers.
   - ARIA labels on dynamic elements, toggles, and Mock Booth simulated hardware.

4. **Cognitive Load Reduction:**
   - Single-column layouts for complex information.
   - Progress indicators for the JanPath journey.
   - Clear "Back" and "Next" actions without hidden menus.

5. **Multi-lingual Readiness:**
   - UI strings abstracted to allow easy toggling between simple English and simple Hindi, ensuring localized civic education.
